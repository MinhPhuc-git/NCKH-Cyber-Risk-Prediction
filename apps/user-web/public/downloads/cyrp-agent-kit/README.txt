CYRP Agent Kit

Extract this zip file to:

C:\CYRP\AgentKit

After extraction, this folder must contain at least:

C:\CYRP\AgentKit\Invoke-CyrpWazuhBootstrapper.ps1
C:\CYRP\AgentKit\Install-CyrpWazuhFromEnrollmentFile.ps1
C:\CYRP\AgentKit\wazuh-agent.msi

Then open PowerShell as Administrator and run the enrollment command shown in User Portal.

Do not run the command before extracting the full zip file.
Do not copy only Invoke-CyrpWazuhBootstrapper.ps1 by itself.
